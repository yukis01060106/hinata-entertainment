# HINATA Entertainment 公式サイト デザイン方向性の提案

> コンセプト：**「ひなた＝日の当たる場所」**
> 暗闇（夜）から光が生まれ、昼の熱を経て、夕焼けで温かく包まれる。
> 1ページをスクロールすると **「HINATAの一日」** を体験できる構成にします。

---

## 1. 配色（カラーパレット）

ベースは限りなく黒に近い藍色です。光の色は「発光しているように」見せるため、ベタ塗りではなくグラデーションや blend-mode（screen / plus-lighter）で重ねます。

| 役割 | 名前 | HEX | 用途 |
|---|---|---|---|
| ベース | 夜藍 Yoru-ai | `#07091A` | 背景（最暗部） |
| ベース2 | 深藍 Fuka-ai | `#141A3A` | カード背景・夜明け前の空 |
| アクセント1 | 朱 Shu | `#E8452C` | 火の国・熱。CTA、強調 |
| アクセント2 | 橙 Daidai | `#FF8A3D` | 光の中間色 |
| アクセント3 | 金 Kin | `#FFC76B` | 光の芯、ハイライト、スポットライト |
| テキスト | 生成り Kinari | `#F5EEE3` | 本文（純白より柔らかい） |
| サブテキスト | 灰 Hai | `#9A97A8` | 補足テキスト |

**メイングラデーション（夜明け → 夕焼け）**
`#07091A → #141A3A → #E8452C → #FF8A3D → #FFC76B`

- 全体に **フィルムグレイン**（SVGノイズ、不透明度 5〜7%）を固定レイヤーで重ねる
- 光の周囲は `mix-blend-mode: screen` でにじませ、フィルム写真のハレーションを出す

## 2. フォント

すべて Google Fonts（`next/font` でセルフホストし、表示速度への影響を抑える）

| 用途 | フォント | 理由 |
|---|---|---|
| 日本語見出し | **Shippori Mincho B1**（ExtraBold 800） | 太めの明朝で、墨と光のコントラストが出る。和の品と力強さを両立できる |
| 日本語本文 | **Zen Kaku Gothic New**（400 / 700） | スマホでも読みやすく、明朝の見出しとよく合う |
| 英字ディスプレイ | **Unbounded**（700〜900） | 丸みのある幅広のフォントで、太陽の「膨らみ」を感じさせる。HINATAのロゴタイプとマーキーで使う |
| 英字アクセント | **Instrument Serif**（Italic） | セクション番号や「— About」などの小見出しに使う。雑誌っぽい品を加える |

- 見出しは `clamp()` で **画面幅いっぱい**（スマホで約18vw、PCで最大約14vw）に広げる
- 日本語の大見出しは縦書き（`writing-mode: vertical-rl`）も一部で使い、アート作品のようなレイアウトにする

## 3. 全体の演出ルール

| 演出 | 実装方法 | 補足 |
|---|---|---|
| スムーススクロール | **Lenis** | GSAP ScrollTrigger と同期させる |
| スクロール連動 | **GSAP + ScrollTrigger** | 背景色の変化、パララックス、文字の出現 |
| 背景の時間変化 | 固定背景レイヤーのCSS変数（`--sky-top` / `--sky-bottom`）を ScrollTrigger で補間する | 夜明け（Hero/About）→ 昼（Service/Livers）→ 夕焼け（Recruit）→ 夜（Company/Contact） |
| マウス追従の光 | 軽量な **Canvas**（1枚）で、金色の放射グラデーションを lerp（線形補間）で遅れて追従させる | スマホはタッチした位置へ移動し、指を離すとゆっくり中央へ戻る |
| 1文字ずつの出現 | 文字を span に分割し、下からのフェードとブラーを外しながら表示する | 見出しのみに使う（本文には使わない） |
| マーキー | 巨大な英字が横に流れる。スクロール速度に応じて速くなる | セクションの区切りに配置する |
| 磁石ボタン | カーソルに少し吸い寄せられる（最大12px程度） | PCのみ |
| 光の反射 | ホバー時に、カード表面をカーソル位置の光沢（radial-gradient）が走る | スマホはタップ時に一瞬光らせる |
| reduced-motion | `prefers-reduced-motion: reduce` の環境では、Lenis・パララックス・マーキー・Canvas を停止し、フェード表示だけにする | オープニングも短縮する |

**パフォーマンス方針**
- Canvas は1枚だけ使い、画面外やタブが非アクティブのときは描画を止める
- アニメーションは `transform` と `opacity` だけで行う（レイアウトの再計算を起こさない）
- 画像は `next/image`（AVIF/WebP）で配信し、ファーストビューには重い画像を置かない（文字と光だけで見せる）

## 4. セクションごとの演出

### 0. オープニング（約2.5秒・2回目以降の訪問ではスキップ）
1. 真っ暗な画面（`#07091A`）
2. 画面の下端から、金色の光の筋が地平線のように広がる
3. 「HINATA」の文字が **下からせり上がり**、文字の上端から光が当たって色が 暗い藍 → 金 に変わる（日の出の表現）
4. 光が画面全体に拡散してヒーローへ移る

### 1. Hero
- 背景：夜明け前の深い藍。画面下から朱〜金色の「太陽の輪郭」（巨大な円のグラデーション）がのぞいている
- 中央に「**ライバーが、**／**一番輝ける場所へ。**」（明朝体の大見出し。1文字ずつ出現）
- 背景に巨大な英字「HINATA」をうっすら配置し、パララックスでずらす
- CTA「**ライバー応募**」：光沢と磁石の動き付きのピル型ボタン。スマホでは画面下に固定の応募ボタンも表示する（TikTokから来た人がすぐ押せるように）
- 右下に「Scroll」の縦書きと、光の粒が流れ落ちるインジケーター

### 2. About ― 名前の由来
- 雑誌の見開きのようなレイアウト：左に縦書きの巨大な「日向」、右に由来テキストの3つの章
- 各章の見出し（【日の当たる場所へ】など）は明朝体。章番号は Instrument Serif の Italic で「01 / 02 / 03」
- スクロールに合わせて、テキストに差し込む光の角度が変わる（光の帯が斜めに通過する）
- 最後の一文「熊本から、ライバーが一番輝ける『ひなた』をつくる。」は画面いっぱいの大きさで、1文字ずつ光が灯る
- 背景は夜明けの藍から朱色へ変わり始める

### ― マーキー ―
`SHINE ON KUMAMOTO ✺ LIVE FROM KYUSHU ✺ HINATA ENTERTAINMENT ✺`（Unbounded、アウトライン文字と塗り文字を交互に）

### 3. Service
- 2本柱を **大きな2枚のパネル** で見せる
  - **GIFT LIVE**（ギフト配信ライバー）：朱色系の光
  - **SHOP LIVE**（ショップ配信ライバー）：金色系の光
- 各パネルの下に、サポート内容を小さなカードで並べる（例：配信戦略の設計／イベント・ランキング支援／企業案件・商品のマッチング／メンタル・スケジュールのケア／機材・撮影のサポート など）
- カードはホバーで光が反射し、スマホでは横スワイプのカルーセルにする
- 背景は「昼」：朱色から橙へ明るくなる

### 4. Livers
- 縦長（9:16、TikTokと同じ比率）のポートレートカードを横スクロールで並べる（PCはスクロールに合わせて横に流れる。スマホはスワイプ）
- 写真にはフィルム調のデュオトーン（藍×金）をかけ、ホバーでカラーに戻る
- カードには名前（英字と日本語）、ジャンル（Gift / Shop）、TikTokリンク
- **仮の画像と仮の名前** を入れておき、`site.ts` の配列を書き換えるだけで追加・差し替えできるようにする

### ― マーキー ―
`BE THE LIGHT ✺ 未経験OK ✺ FROM KUMAMOTO TO JAPAN ✺`

### 5. Recruit
- 背景は **夕焼け**：画面全体が橙から金色に染まる最も明るいセクション（文字色は深藍に反転させる）
- 大見出し「**あなたにも、ひなたを。**」（案）
- 訴求ポイントを大きな数字や言葉で見せる：「未経験OK」「熊本・九州から全国へ」「スマホ1台ではじめられる」「専属マネージャーがつく」 など
- **応募の流れ**：STEP 01〜04 を横長のタイムラインで表示し、スクロールに合わせて光の線が伸びて各ステップが灯る
  - 01 応募フォーム送信 → 02 面談（オンライン可） → 03 契約・配信準備 → 04 デビュー
- CTA「ライバー応募はこちら」

### 6. Company
- 夕焼けが沈み、再び夜の藍へ戻る
- 飾りを抑えた定義リスト形式（事務所名／運営会社：株式会社Rise Tech Solutions／所在地：熊本県〇〇（仮）／事業内容）
- 余白を多く取った静かなセクション

### 7. Contact
- タブで2つのフォームを切り替える：**「ライバー応募」** と **「企業のお問い合わせ」**（ショップ配信の依頼など）
- ライバー応募の項目：名前、年齢、居住地、TikTokアカウント、配信経験の有無、希望ジャンル（ギフト／ショップ）、連絡先、自由記入
- 企業のお問い合わせの項目：会社名、担当者名、メール、電話、お問い合わせ種別、内容
- 入力欄はフォーカスすると下線が金色に光る
- フッター：巨大な「HINATA」のロゴタイプを画面いっぱいに置き、下半分が地平線で切れている（沈む太陽のように）

## 5. 技術構成（確認用）

- **Next.js（App Router）+ TypeScript + Tailwind CSS**
- **GSAP + ScrollTrigger**（アニメーション）/ **Lenis**（スムーススクロール）
- **データは `src/content/site.ts` の1ファイルにまとめる**（テキスト、ライバー一覧、サービス、会社情報、SEO文言）。画像は `public/images/` に置く
- SEO：`metadata` API で title・description・keywords（熊本 ライバー事務所／九州 ライバー事務所／TikTok LIVE 事務所）、構造化データ（Organization / LocalBusiness の JSON-LD）、`sitemap.ts`、`robots.ts`
- **OGP画像**：`opengraph-image.tsx`（next/og）で、ブランドの配色を使った画像を自動生成する
- 下層ページ：まずは1ページで作り、必要であれば `/recruit`（募集要項の詳細）と `/privacy`（プライバシーポリシー。応募フォームがあるため必要）を追加する
